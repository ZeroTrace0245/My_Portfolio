# SmartBite

SmartBite is a nutrition & lifestyle platform that helps users track meals, hydration, and goals while receiving AI-driven guidance and personalized recommendations.

## Purpose
Enable healthier habits through meal tracking, pathway programs (Diet/Gym/General), goal-setting, dashboards, and community features with role-aware admin tools.

## Key features
- AI Coach chat
- Meal nutrition estimation
- Reports & dashboards
- User goals, shopping & payments
- Pathway-based programs (Diet, Gym, General)

## Tech stack
- Frontend: Blazor Server (.NET 11)
- Backend: ASP.NET Core Minimal API
- Database: EF Core + PostgreSQL
- Cache: Redis
- Hosting: Aspire / Azure
- Containerization: Docker

## Running notes
- Requires .NET 10 or .NET 11 Preview SDK
- Docker recommended
- Migration warnings may appear but are non-blocking
