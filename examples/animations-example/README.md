Animations example (React + Tailwind)

Quick start:

1. cd examples/animations-example
2. npm install
3. npm run dev

Files added:
- package.json, vite entrypoint
- tailwind/postcss config
- src/components/AnimatedButton.jsx
- src/components/AnimatedCard.jsx
- src/App.jsx (demo page)

These components use Tailwind utility classes for transitions and transforms. They can be copied into any React + Tailwind project.
